## 📚 附录：知识库共享机制说明

### 共享架构特点
DeepTutor在RK3566-iStoreOS上采用全局共享的知识库架构：

- **单一实例**：运行一个DeepTutor容器实例
- **共享知识库**：所有访问者使用同一套知识库数据
- **统一配置**：相同的API密钥和配置参数
- **集中存储**：知识库文件统一存储在设备上

### 用户体验影响

#### 优点
✅ **资源共享**：避免重复上传相同文档
✅ **成本效益**：节省存储空间和API调用费用
✅ **协同学习**：多人可以共同建设和完善知识库
✅ **维护简单**：只需管理一套知识库数据

#### 需要考虑的问题
⚠️ **隐私concern**：敏感文档可能被其他用户访问
⚠️ **权限管理**：无法控制不同用户的访问权限
⚠️ **数据隔离**：用户间缺乏数据边界

### 可选解决方案

如果您需要用户隔离，可以考虑以下方案：

#### 1. 多实例部署
```bash
# 为不同用户组部署独立的DeepTutor实例
docker-compose up -d --scale deeptutor=3
```

#### 2. 命名空间隔离
在知识库名称中加入用户标识：
- `user1_project_docs`
- `user2_research_papers`

#### 3. 访问控制层
通过反向代理或中间件实现用户路由

### 使用建议

对于家庭或小团队使用场景：
1. **明确使用群体**：共享模式通常很合适
2. **文档分类管理**：通过合理的命名和分类来组织知识库
3. **定期清理**：及时删除不再需要的文档
